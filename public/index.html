02

Информация и её свойства

Информация — сведения об окружающем мире, которые уменьшают неопределённость наших знаний.

«Информация — это не материя и не энергия»— Норберт Винер
  • Объективность — не зависит от чьего‑то мнения
  • Достоверность — отражает истинное положение дел
  • Полнота — достаточна для принятия решения
  • Актуальность — важна в данный момент
  • Полезность — решает задачу получателя
  • Понятность — выражена на понятном языке

Кодирование текста

Каждому символу соответствует число. ASCII — 128 символов, Unicode — больше 150 000, включая кириллицу и эмодзи.

Программирование

Программа — алгоритм, записанный на языке, понятном компьютеру.

Python C++ JavaScript Java Pascal
even.py
def is_even(n):
    return n % 2 == 0

for i in range(1, 6):
    print(i, "чётное" if is_even(i)
             else "нечётное")
